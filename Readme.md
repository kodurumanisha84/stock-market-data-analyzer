# 📈 Stock Market Data Analyzer

An interactive and industry-oriented Stock Market Data Analyzer built using Python, Streamlit, Plotly, and Yahoo Finance API.

This project helps users analyze historical stock market data, visualize trends, calculate technical indicators, evaluate volatility, and generate financial insights through an interactive dashboard.

# 📌 Project Overview

The Stock Market Data Analyzer is a financial analytics system that fetches real-time and historical stock market data and performs:

- Price trend analysis
- Moving average analysis
- Daily return calculations
- Volatility/risk analysis
- Interactive financial visualizations
- Technical indicator analysis

This project simulates how FinTech companies and financial analysts use Python-based systems to analyze stock market behavior.

---

# 🎯 Problem Statement

Investors and analysts often need tools to understand:

- How stock prices move
- Risk associated with investments
- Market trends
- Stock performance over time

Manual analysis using spreadsheets becomes difficult for large datasets.

This project automates stock data analysis using Python and interactive visual dashboards.

# 🖥️ Installation Guide

## Step 1 — Clone Repository

```bash
git clone https://github.com/kodurumanisha84/stock-market-data-analyzer.git
```

---

## Step 2 — Open Project

```bash
cd stock-market-data-analyzer
```

---

## Step 3 — Create Virtual Environment

### Windows

```bash
python -m venv venv
venv\Scripts\activate
```
---

## Step 4 — Install Dependencies

```bash
pip install -r requirements.txt
```

---

# ▶️ How to Run the Project

## Run Dashboard

```bash
streamlit run dashboard.py
```

---

## Run Analysis Script

```bash
python main.py
```
